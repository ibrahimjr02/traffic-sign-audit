# Data folder

This folder holds the GTSRB dataset. The dataset is not included in this repository.

1. Download the archive from the Zenodo record: https://zenodo.org/records/13741936
   (dataset information: https://benchmark.ini.rub.de/gtsrb_dataset.html).
2. Extract it so that this folder contains `Train.csv`, `Meta.csv`, `Test.csv`,
   `signnames.csv` and the `Train`, `Test` and `Meta` image folders.

Dataset citation: German Traffic Sign Recognition Benchmark (GTSRB), Real-Time
Computer Vision Group, Ruhr-Universität Bochum.
